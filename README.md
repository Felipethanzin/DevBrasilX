## 📌 Sobre o Projeto

O **DevBrasilX** é uma aplicação **Web e Mobile** moderna desenvolvida em **Flutter & Dart**, criada para ser a principal rede social e plataforma de aprendizagem com **Inteligência Artificial** integrada para a comunidade de Tecnologia da Informação do Brasil.

Seja você um estudante iniciante, um programador experiente ou um curioso da área, o DevBrasilX oferece um ambiente seguro, livre para todas as idades e recheado de ferramentas interativas para turbinar seus estudos e networking dev.

## 🌟 Principais Funcionalidades

### 🌐 1. Rede Social para Devs
- **Feed de Publicações:** Postagens com suporte a textos, links, imagens e blocos de código formatados.
- **Abas de Conteúdo:** Alterne facilmente entre *Para você*, *Seguindo* e *Recentes*.
- **Perfil Dev Personalizado:** Exiba suas conquistas, stacks de tecnologia e repositórios favoritos.
- **Comunidades & Desafios:** Participe de grupos de estudo, fóruns e desafios práticos de código.

### 🤖 2. Ferramenta de Estudos com IA Integrada
- **Assistente Dev Inteligente:** Tire dúvidas de programação, solicite explicações de algoritmos e faça refatoração de código em tempo real.
- **Tutoriais & Dicas:** Trilhas de estudo organizadas para diversos níveis e tecnologias (Frontend, Backend, Mobile, DevOps, etc.).

### 🔒 3. Autenticação & Segurança de Ponta
- **Verificação via SMS / Número de Telefone:** Camada extra de proteção contra spam e robôs.
- **Social Login:** Acesso rápido via Google e Facebook.
- **Ambiente Livre & Seguro:** Livre para todas as idades, promovendo um ecossistema saudável para estudantes e profissionais.

## 🛠️ Arquitetura e Tecnologias

### **Client (App & Web)**
- **Framework:** [Flutter](https://flutter.dev/) (Multiplataforma: Android, iOS, Web)
- **Linguagem:** [Dart](https://dart.dev/)
- **Gerenciamento de Estado:** Provider / Bloc / GetX *(Ajuste conforme o seu projeto)*

### **Backend & Banco de Dados**
- **API REST / GraphQL:** Conexão direta via requisições HTTP assíncronas
- **Banco de Dados:** PostgreSQL / MySQL / Firebase Firestore
- **Sistema de SMS:** Twilio / Firebase Authentication (Verificação de Número)
- **Inteligência Artificial:** Integração via API (OpenAI / Gemini)
